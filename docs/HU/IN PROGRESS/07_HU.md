# 📊 **\[HU07] - Borrador de desarrollo**
### Objetivo:

Mostrar al coordinador un resumen visual y estadístico del uso del sistema: tutorías por materia, por estado, por tutor, etc.

---

### Mínimo funcional:

* Tabla con todas las tutorías registradas.
* Filtros por fecha, materia o tutor.
* Totales: tutorías agendadas, realizadas, rechazadas.
* Exportación a PDF o CSV (si se incluye con HU10).

---

### Estructura sugerida:

* **Backend**

  ```js
  app.get('/api/reportes/tutorias', verificarToken, soloCoordinadores, async (req, res) => {
    const [datos] = await db.query(`
      SELECT t.*, est.nombre AS estudiante, tut.nombre AS tutor
      FROM tutoria t
      JOIN usuario est ON est.id = t.estudiante_id
      JOIN usuario tut ON tut.id = t.tutor_id
      ORDER BY t.fecha DESC
    `);
    res.json(datos);
  });
  ```

* **Frontend**

  * Tabla con filtros dinámicos.
  * Botón de exportar.
  * Gráfica de barras o pastel si se usa alguna librería JS (ej. Chart.js).

---

### Validación:

* Solo el coordinador accede.
* Datos ordenados por fecha.
* Se pueden aplicar filtros (por fecha, materia, tutor).
* Información exportable opcional.
