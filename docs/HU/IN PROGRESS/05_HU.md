# **\[HU05] - Borrador de desarrollo**

**Como tutor, quiero registrar estudiantes para asignar una tutoria.**

---

### Objetivo:

Permitir que los tutores registren comentarios u observaciones sobre la sesión después de realizada, visibles para el estudiante y el coordinador.

---

### Mínimo funcional:

* Campo de texto para ingresar la observación.
* Botón de “Guardar observación”.
* Guardado en la base de datos junto a la tutoría correspondiente.

---

### Estructura sugerida:

* **Backend**

  ```js
  app.put('/api/tutorias/:id/observacion', verificarToken, soloTutores, async (req, res) => {
    const { observaciones } = req.body;
    const { id } = req.params;

    await db.query(`UPDATE tutoria SET observaciones = ? WHERE id = ?`, [observaciones, id]);
    res.json({ mensaje: "Observación registrada" });
  });
  ```

* **Frontend**

  * Mostrar tutorías asignadas al tutor.
  * Campo de texto por cada sesión + botón para registrar la observación.


### Validación:

* Solo el **tutor asignado** puede asignar tutorias.
