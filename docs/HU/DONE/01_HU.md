# **\[HU01] - Desarrollo completo**

 **Como estudiante, quiero registrarme e iniciar sesión para poder acceder a las tutorías.**

---

### 1. **Análisis funcional**

#### Actor:

* Estudiante (aunque también aplica para tutores y coordinadores).

#### Objetivo:

* Iniciar sesión en la plataforma para acceder al sistema según su rol.

#### Funcionalidades clave:

* Registro con nombre, email, contraseña.
* Inicio de sesión con autenticación.
* Redirección al panel según su **rol** (`estudiante`, `tutor`, `coordinador`).
* Validaciones básicas (email válido, contraseña mínima).
* Seguridad mínima: contraseña cifrada y sesión persistente.

---

### 2. **Modelo de datos (tabla `usuario`)**

Basado en tu modelo relacional:

```sql
CREATE TABLE usuario (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    contraseña VARCHAR(255) NOT NULL,
    rol ENUM('estudiante', 'tutor', 'coordinador') NOT NULL,
    createdAt DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

---

### 3. **Seguridad**

* Contraseña cifrada con `bcrypt`.
* Autenticación mediante **JWT (JSON Web Token)**.
* Middleware para verificar token en cada acceso protegido.

### 5. **Lógica Backend (ejemplo en Node.js + Express)**

#### Registro

```js
const bcrypt = require('bcrypt');
const jwt = require('jsonwebtoken');

app.post('/api/registro', async (req, res) => {
  const { nombre, email, contraseña, rol } = req.body;
  const hashedPassword = await bcrypt.hash(contraseña, 10);

  await db.query(`INSERT INTO usuario (nombre, email, contraseña, rol) VALUES (?, ?, ?, ?)`,
    [nombre, email, hashedPassword, rol]);

  res.status(201).json({ mensaje: "Usuario registrado correctamente" });
});
```

#### Login

```js
app.post('/api/login', async (req, res) => {
  const { email, contraseña } = req.body;
  const [usuario] = await db.query(`SELECT * FROM usuario WHERE email = ?`, [email]);

  if (!usuario) return res.status(401).json({ mensaje: "Usuario no encontrado" });

  const valido = await bcrypt.compare(contraseña, usuario.contraseña);
  if (!valido) return res.status(401).json({ mensaje: "Contraseña incorrecta" });

  const token = jwt.sign({ id: usuario.id, rol: usuario.rol }, "secreto", { expiresIn: '2h' });

  res.json({ mensaje: "Login exitoso", token });
});
```
