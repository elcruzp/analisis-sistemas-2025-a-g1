# **\[HU03] - Desarrollo completo**

 **Como estudiante, quiero solicitar tutorías y ver mi historial para llevar seguimiento de mi proceso.**

---

### 1. **Análisis funcional**

#### Actor:

* Estudiante

#### Objetivos:

* Solicitar una tutoría con un tutor disponible, indicando materia, fecha y hora.
* Ver el historial de tutorías realizadas o solicitadas, incluyendo estado y observaciones.

#### 📋 Campos requeridos para solicitar tutoría:

* Estudiante (autenticado)
* Tutor seleccionado
* Materia
* Fecha y hora de la tutoría
* Observaciones iniciales (opcional)

---

### 2. **Modelo de datos (tabla `tutoria`)**

```sql
CREATE TABLE tutoria (
    id INT PRIMARY KEY AUTO_INCREMENT,
    estudiante_id INT NOT NULL,
    tutor_id INT NOT NULL,
    materia VARCHAR(100) NOT NULL,
    fecha DATETIME NOT NULL,
    estado ENUM('pendiente', 'aceptada', 'rechazada', 'realizada') DEFAULT 'pendiente',
    observaciones TEXT,
    createdAt DATETIME DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (estudiante_id) REFERENCES usuario(id),
    FOREIGN KEY (tutor_id) REFERENCES usuario(id)
);
```

### 4. **Lógica Backend (Node.js + Express)**

#### Solicitar tutoría:

```js
app.post('/api/tutorias', verificarToken, async (req, res) => {
  const { tutor_id, materia, fecha, observaciones } = req.body;
  const estudiante_id = req.usuario.id;

  await db.query(`INSERT INTO tutoria (estudiante_id, tutor_id, materia, fecha, observaciones)
                  VALUES (?, ?, ?, ?, ?)`, [estudiante_id, tutor_id, materia, fecha, observaciones]);

  res.status(201).json({ mensaje: "Tutoría solicitada correctamente" });
});
```

#### Obtener historial:

```js
app.get('/api/tutorias/mias', verificarToken, async (req, res) => {
  const estudiante_id = req.usuario.id;

  const [tutorias] = await db.query(`
    SELECT t.*, u.nombre AS tutor_nombre
    FROM tutoria t
    JOIN usuario u ON u.id = t.tutor_id
    WHERE estudiante_id = ?
    ORDER BY fecha DESC
  `, [estudiante_id]);

  res.json(tutorias);
});
```

### 🛡️ 5. **Validaciones y reglas**

* No se pueden solicitar tutorías en fechas pasadas.
* El sistema puede verificar que el tutor tenga disponibilidad (si se implementa calendario).
* El historial solo muestra tutorías propias del estudiante autenticado.

### 7. **Documentación técnica**

 Este módulo permite a los estudiantes crear solicitudes de tutoría indicando el tutor, materia, fecha y observaciones. Las tutorías se registran con estado inicial "pendiente" y pueden cambiar a "aceptada", "realizada" o "rechazada" según el flujo definido.

 El historial permite al estudiante ver todas sus solicitudes, su estado actual y los comentarios añadidos por el tutor, mejorando el seguimiento académico.
