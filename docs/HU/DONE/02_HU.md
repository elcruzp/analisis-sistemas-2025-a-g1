# **\[HU02] - Desarrollo completo**

 **Como tutor o coordinador, quiero iniciar sesión con mi rol para acceder a mis funcionalidades.**

---

### 1. **Análisis funcional**

#### Actor:

* Tutor
* Coordinador académico

#### Objetivo:

* Iniciar sesión en la plataforma con su rol específico y acceder **exclusivamente a las funcionalidades que les corresponden**.

---

### 2. **Funcionalidades clave**

* Iniciar sesión con email y contraseña.
* Acceso restringido por rol:

  * El **tutor** puede:

    * Ver y gestionar sus tutorías.
    * Registrar observaciones.
    * Ajustar disponibilidad.
  * El **coordinador** puede:

    * Supervisar el estado del sistema.
    * Generar reportes.
    * Ver actividad de todos los usuarios.
* Redirección a su respectivo panel.
* Seguridad con JWT.

---

### 3. **Modelo de datos**

Ya definida en HU01 con campo `rol`, este campo se aprovecha ahora para **redireccionar** o **controlar accesos**.

```sql
rol ENUM('estudiante', 'tutor', 'coordinador')
```

---

### 4. **Control de acceso según rol**

#### Backend – Middleware de autenticación (Node.js)

```js
function verificarToken(req, res, next) {
  const token = req.headers['authorization'];
  if (!token) return res.status(403).json({ mensaje: 'Token requerido' });

  try {
    const datos = jwt.verify(token, 'secreto');
    req.usuario = datos;
    next();
  } catch (err) {
    res.status(401).json({ mensaje: 'Token inválido' });
  }
}
```

#### Middleware por rol

```js
function soloTutores(req, res, next) {
  if (req.usuario.rol !== 'tutor') {
    return res.status(403).json({ mensaje: 'Acceso denegado' });
  }
  next();
}

function soloCoordinadores(req, res, next) {
  if (req.usuario.rol !== 'coordinador') {
    return res.status(403).json({ mensaje: 'Acceso denegado' });
  }
  next();
}
```

---

### 5. **Interfaz (Frontend Web)**

Después del login, según el `rol` recibido en la respuesta del backend, se redirige al panel correspondiente:

```js
if (rol === 'tutor') {
  window.location.href = '/dashboard-tutor.html';
} else if (rol === 'coordinador') {
  window.location.href = '/dashboard-coordinador.html';
}
```

---

### 6. **Funciones por rol (mínimo viable)**

#### Tutor:

* `/api/tutorias/asignadas` → Ver tutorías asignadas.
* `/api/tutorias/:id/observar` → Registrar observaciones.
* `/api/disponibilidad` → Ajustar disponibilidad horaria.

#### Coordinador:

* `/api/reportes` → Ver reportes de tutorías.
* `/api/usuarios` → Ver actividad de usuarios.
* `/api/tutorias` → Consultar todas las sesiones.
